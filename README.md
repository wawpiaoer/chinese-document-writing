# 中文制式文档写作

有一份写好的模板、样章或样例，再给我新文档的目录和资料，我就可以按同一套标题层级、栏目、表格和版式写成新的中文 Word 文档。比如，你给我一章样稿，我可以按它的格式写另一章。你也可以给我一份报告样例，让我用新的材料写一份结构一致的报告。

适用范围包括书稿、教材、项目方案、工作报告、操作手册和培训材料等有固定结构的中文文档。需要按同一模板继续写第二章、第二份时，每份单独商议。

1. 一份可参照的模板、样章或完整样例，用来明确标题、模块、表格等格式。
2. 这次要写的目录或提纲，以及读者、用途和需要覆盖的内容。
3. 写作需要的事实、资料或数据。涉及计算时，请同时给原始数据和计算口径。
